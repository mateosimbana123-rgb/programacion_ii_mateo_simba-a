# Programación II

Repositorio académico de la materia **Programación II**, destinado al desarrollo, organización y control de proyectos y subproyectos realizados durante el curso.

En este repositorio se trabajará principalmente con **Python**, **Django** y **Odoo**, aplicando conceptos de programación, desarrollo web, bases de datos, arquitectura de aplicaciones y desarrollo de módulos empresariales.

---

## Tecnologías

### 🐍 Python

**Python** es un lenguaje de programación de alto nivel, interpretado y de propósito general. Se caracteriza por tener una sintaxis sencilla y legible, lo que facilita el desarrollo de aplicaciones y el aprendizaje de conceptos de programación.

Durante la materia se utilizará Python como lenguaje principal para desarrollar ejercicios, aplicaciones y proyectos.

**Principales características:**

- Sintaxis clara y sencilla.
- Programación orientada a objetos.
- Amplia variedad de librerías y frameworks.
- Manejo de archivos y bases de datos.
- Desarrollo de aplicaciones y automatización.
- Amplio uso en desarrollo web, ciencia de datos e inteligencia artificial.

---

### 🌐 Django

**Django** es un framework web de código abierto desarrollado en Python. Permite crear aplicaciones web de forma estructurada, segura y escalable.

Django utiliza principalmente el patrón **MVT (Model-View-Template)** para organizar los diferentes componentes de una aplicación web.

Durante la materia se utilizará Django para desarrollar aplicaciones web utilizando Python y bases de datos.

**Principales características:**

- Framework basado en Python.
- Arquitectura MVT.
- Sistema ORM para trabajar con bases de datos.
- Sistema de autenticación de usuarios.
- Panel administrativo.
- Manejo de URLs, formularios y plantillas.
- Desarrollo rápido de aplicaciones web.

---

### 🏢 Odoo

**Odoo** es una plataforma empresarial de código abierto que integra diferentes aplicaciones para la gestión de organizaciones.

Odoo está desarrollado principalmente utilizando **Python** y utiliza una arquitectura modular que permite crear y personalizar módulos para diferentes necesidades empresariales.

Durante la materia se estudiará el desarrollo y personalización de módulos utilizando Python y las tecnologías utilizadas por Odoo.

**Principales características:**

- Arquitectura modular.
- Desarrollo de módulos con Python.
- Gestión de bases de datos.
- Modelos y ORM.
- Vistas XML.
- Gestión de usuarios y permisos.
- Aplicaciones empresariales.
- Integración entre diferentes módulos.

## 🌿 Control de versiones

El repositorio utiliza **Git** para llevar el control de versiones de los proyectos.

Los cambios realizados deberán registrarse mediante commits descriptivos.

Ejemplo:

```bash
git add .
git commit -m "Agrega proyecto inicial de Django"
git push
```

Para consultar el estado del repositorio:

```bash
git status
```

Para consultar el historial:

```bash
git log
```
